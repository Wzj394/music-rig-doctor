# 链路详解：为什么必须这样接

> 这份文档解释**拓扑**，不解释按钮在哪。
> 看懂了这个，你自己就能判断"我到底该不该加一个通道"。

---

## 一、核心矛盾：ASIO 是独占的

先理解这一条，其他都是推论。

```
ASIO 的设计目标    →  低延迟
实现方式          →  **独占**声卡，绕过 Windows 音频子系统
副作用            →  Windows 上的其他程序（会议、OBS、浏览器）
                       **拿不到那块声卡的输入输出**
```

**所以：**

```
DAW 用 ASIO 占住声卡
    →  延迟很低  ✅
    →  但会议软件录不到你  ❌
```

**这就是为什么需要 Voicemeeter —— 它不是"更好的驱动"，它是一个**中间人**：**

```
声卡 ──ASIO──▶ Voicemeeter ──┬──▶ 声卡输出（给 DAW 之外的东西留一条路）
                             └──▶ 虚拟设备（Windows 程序能读能写）
```

**Voicemeeter 独占声卡，然后把声音**重新广播**成 Windows 认识的样子。**

---

## 二、两条总线：A1 和 B1

**这是整个体系里最重要的心智模型。**

```
                ┌─────────────────────────────────────┐
   麦克风 ──────▶│                                     │
   DAW ────────▶│           Voicemeeter               │
   系统声音 ────▶│                                     │
                │  每条通道上有两排按钮：               │
                │     A1 A2 A3  ──▶  物理输出（耳机/音箱）
                │     B1 B2     ──▶  虚拟输出（给别人）
                └─────────────────────────────────────┘
```

```
A1  =  **给你自己听的**
      绑定到声卡的物理输出
      你戴着耳机听到的就是它

B1  =  **给别人听的**
      绑定到虚拟录音设备
      会议软件 / OBS / 直播软件 读的就是它
```

**记住这一句，90% 的问题都能自己定位：**

> **"我听不到" → 查 A1。**
> **"对面听不到 / 录不到" → 查 B1。**

## 三、典型场景的接线

### 场景 A：录课 / 线上教学

```
声卡输入（麦克风）
    ├─▶ 硬件直通 ──▶ 你的耳机          0 延迟，你听得到自己
    └─▶ Strip[0] ──▶ B1 ──▶ 学生        只录不听，**不会回声**

DAW（放演示音频）
    └─▶ Strip[n] ──▶ A1（你听）+ B1（学生听）

系统声音（浏览器里的参考曲）
    └─▶ Strip[m] ──▶ A1 + B1

而 Strip[0].A1 = 0
    →  Voicemeeter 不监听麦克风
    →  耳机里只有硬件直通那一路
    →  **回声消失**
```

**关键点：**

```
麦克风的"监听"和"录制"是两条路
    · 监听取硬件直通（0 延迟）
    · 录录取 B1
    · 两条路并行不冲突 —— 但如果你让 Voicemeeter 也监听，
      它就变成了第二条监听路，和硬件直通叠加 → 回声
```

### 场景 B：编曲 / 录音（不出网）

```
DAW ──▶ A1（只听自己）
B1 全部关掉
    →  保证没有任何东西漏到会议或直播
    →  也避免 OBS 之类的软件在后台偷偷录音
```

## 四、DAW 的输出进了哪条通道

**这是最容易配错的一环。**

Voicemeeter 给每个虚拟输入都提供了一个**独立的 ASIO 驱动**：

| DAW 里选的驱动 | 声音进哪条 Strip | 说明 |
|---|---|---|
| `Voicemeeter Virtual ASIO` | Strip[3]（VAIO，第一条虚拟输入） | Windows 系统声音默认也在这里 |
| `Voicemeeter AUX Virtual ASIO` | Strip[4]（AUX，第二条虚拟输入） | 常用来单独放 DAW |
| `Voicemeeter Insert Virtual ASIO` | insert 通道 | 用于串联处理，不是主链路 |

**配错的典型症状：DAW 在播、电平在动，但听不到，Voicemeeter 里也没有通道在跳。**

**怎么查：**

```powershell
# REAPER 的例子
Select-String -Path "$env:APPDATA\REAPER\reaper.ini" -Pattern 'asio_driver_name'
```

```
asio_driver_name = "Voicemeeter AUX Virtual ASIO"
        ↓
声音在 Strip[4]，去配 Strip[4] 的 A1 / B1
```

**怎么确认：**DAW 播放时，看 Voicemeeter 里**哪条通道的电平表在跳** —— 那条就是它进的地方。

### 为什么推荐把 DAW 单独放 AUX

```
系统声音 → VAIO（Strip[3]）
DAW      → AUX （Strip[4]）
    →  两个独立推子
    →  讲课时可以单独压低音乐、放大讲解
```

**如果 DAW 也用 VAIO，它就会和系统声音混在一条推子上，没法单独控。**

## 五、采样率与缓冲

### 采样率必须一致

```
工程 44.1kHz + 设备 48kHz
    →  每次播放都实时重采样
    →  多一层 CPU 开销
    →  多一点点延迟
    →  采样器插件（Kontakt 等）会弹窗要求重启
```

**统一到一个值。改设备比改工程安全**（改工程可能让音色重新加载、时间轴错位）。

### 缓冲是相加的，不是取最大

```
DAW 的 ASIO buffer
    +  Voicemeeter 的 buffer
    ────────────────────────
       =  总延迟
```

**用了 Voicemeeter 中转，就必然至少两层。** 两层都要降。

参考值（48kHz）：

| buffer | 延迟 | 适用 |
|---|---|---|
| 2048 | 43ms | 只看波形 |
| 512 | 11ms | **录课 / 直播** |
| 256 | 5ms | 实时演奏 |
| 64 | 1.3ms | 极限，容易爆音 |

## 六、为什么会议软件要选 `Voicemeeter Out B1`

```
会议软件走 Windows 音频（WASAPI / MME）
    →  它看不到 ASIO 独占的声卡
    →  但它看得到 Voicemeeter 的虚拟设备

而 Voicemeeter 的虚拟**录音**设备就叫：
    Voicemeeter Out B1
    Voicemeeter Out B2
    ...
```

**选 `Voicemeeter Out B1` = 让会议软件读你在 B1 上混好的那一份。**

```
反过来：如果你在会议软件里选声卡本身
    →  它读不到（被 ASIO 独占）
    →  对面听不见你
    →  而你自己听得见（因为你的监听走的是 A1 / 硬件直通）
    →  **"我听得见、对面听不见" 就是这么来的**
```

## 七、这张图，抄下来

```
┌──────────────────────────────────────────────────────────┐
│  声卡  ──ASIO──▶  Voicemeeter                            │
│                     │                                     │
│   麦克风 ──────────▶│ Strip[0]  A1=0  B1=1  Mono=1         │
│                     │            └── 只录不听，防回声       │
│                     │                                     │
│   系统声音 ────────▶│ Strip[3]  A1=1  B1=1                 │
│                     │                                     │
│   DAW ────────────▶│ Strip[4]  A1=1  B1=1                 │
│                     │                                     │
│                     ├── A1 ──▶ 声卡物理输出 ──▶ 你的耳机   │
│                     └── B1 ──▶ 虚拟输出 ──▶ 会议 / OBS    │
└──────────────────────────────────────────────────────────┘

声卡 MIX 旋钮  →  拧到"直通"侧（你听自己，0 延迟）
                 此时 A1 上不要再放麦克风，否则回声
```
